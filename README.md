# PCL3

**PCL3**，即三氯化磷（Phosphorus Trichloride，PCl₃），无色透明液体，用于制造有机磷化合物。

本仓库基于 [PCL CE](https://github.com/PCL-Community/PCL-CE)（Plain Craft Launcher Community Edition）改编。
